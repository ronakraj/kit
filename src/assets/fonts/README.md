# Bundled fonts

Self-hosted rather than loaded from Google Fonts at runtime, since Kit is a local-first app that should work fully offline.

- **IBM Plex Sans** (variable, weights 400–700) and **IBM Plex Mono** (400, 500) — © IBM, licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/).
- **Source Serif 4** (variable, weights 500–700) — © Adobe, licensed under the SIL Open Font License 1.1.

Both families permit embedding and redistribution under the OFL. Files are the unmodified `latin` subset as served by Google Fonts.
